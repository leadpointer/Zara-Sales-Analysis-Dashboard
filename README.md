# Zara Sales Dataset

This dataset contains sales-related information for Zara clothing products, categorized by gender sections (Men and Women), product details, and promotional characteristics. It is useful for performing business analysis, understanding customer preferences, and evaluating the impact of promotions and seasons on sales.

---

## 📂 Dataset Overview

| Column Name         | Description                                                                 |
|---------------------|-----------------------------------------------------------------------------|
| `Product ID`        | Unique identifier for each product                                          |
| `Product Position`  | Placement of the product in the store (e.g., Aisle, End-cap)                |
| `Promotion`         | Whether the product was on promotion ("Yes" or "No")                        |
| `Seasonal`          | Whether the product is seasonal ("Yes" or "No")                             |
| `Sales Volume`      | Number of units sold                                                        |
| `name`              | Name or title of the product                                                |
| `price`             | Price of a single unit of the product                                       |
| `terms`             | Category type of the product (e.g., jackets, trousers)                      |
| `section`           | Gender section where the product is sold ("Man" or "Woman")                 |
| `Total`             | Total sales amount (calculated as `Sales Volume` × `price`)                 |
